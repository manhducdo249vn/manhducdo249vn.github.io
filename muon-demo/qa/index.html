About this demo

  • Model: GPT with 4 layers, width 256, 4.5M parameters. Data: 4,096 people in 13 frequency groups; group g has 2g−1 people, each seen 212−g times per epoch.
  • Both models: seed 0, checkpoint at step 10,000, batch 64. Adam learning rate 5e-4; Muon 0.002 on the hidden matrices, Adam 5e-4 on embeddings, output head and norms.
  • The models run in your browser. Answers are greedy and match the Python code exactly (checked on 24 answers).
  • Code and results: the course repository. Paper: arXiv:2509.26030. One-layer simulation: Tail-End Memory Simulator.
